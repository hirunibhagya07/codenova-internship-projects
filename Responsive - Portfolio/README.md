# Responsive Portfolio Website

A personal portfolio website created for my CodeNova Frontend Development Internship. It introduces my background, skills, projects, and contact information through a responsive and interactive interface.

## Live Demo

[Visit the Portfolio Website](https://hirunibhagya07.github.io/codenova-internship-projects/Responsive%20-%20Portfolio/index.html)

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Semantic Hero, About, Skills, Projects, and Contact sections
- Dark and light theme toggle
- Mobile-friendly navigation

## Technologies Used

- HTML5
- CSS3, Flexbox, and Grid
- JavaScript

## How to Run Locally

1. Clone or download this repository.
2. Open the `Responsive - Portfolio` folder in VS Code.
3. Open `index.html` using the Live Server extension.
